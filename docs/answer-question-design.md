# ReadPilot 答题功能设计

## 概述

在 ReadPilot 扩展中新增"答题"功能：自动分析当前页面内容，检测所有题目并生成答案，以侧边面板形式展示。

## 用户场景

- 用户在网页上浏览包含题目的页面（如试卷、练习题、Quiz 等）
- 用户点击扩展图标，在 popup 中点击"答题"按钮
- 扩展自动分析页面内容，提取题目并生成答案
- 侧边面板展示所有题目和答案

## 功能流程

```
用户点击 Popup "答题" 按钮
        ↓
content.js 提取页面主体内容
        ↓
popup.js 调用 AI API，发送提示词
        ↓
AI 返回 { questions: [{q: "...", a: "..."}, ...] }
        ↓
侧边面板渲染题目和答案列表
        ↓
用户可关闭侧边面板
```

## UI 变更

### Popup 变更

- 新增"答题"按钮，与"摘要页面"并列
- 按钮点击后显示 loading 状态
- 答题完成后侧边面板自动出现

### 侧边面板设计

| 属性 | 值 |
|------|-----|
| 位置 | 页面右侧固定 |
| 宽度 | 360px |
| 背景 | 深色半透明（rgba(15, 23, 42, 0.95)） |
| z-index | 2147483647 |
| 关闭方式 | 点击关闭按钮 / ESC 键 |
| 内容 | 题目列表 + 答案，可滚动 |

### 面板内部结构

```
┌─────────────────────────┐
│  答题结果           [X] │  ← 标题 + 关闭按钮
├─────────────────────────┤
│  Q1: 题目内容          │
│  A: 答案内容           │
├─────────────────────────┤
│  Q2: 题目内容          │
│  A: 答案内容           │
├─────────────────────────┤
│  ...                   │
└─────────────────────────┘
```

## AI Prompt

```
你是一个答题助手。请分析以下页面内容，找出所有题目（问句形式）并给出准确答案。
返回格式为 JSON：
{
  "questions": [
    {"question": "题目1", "answer": "答案1"},
    {"question": "题目2", "answer": "答案2"}
  ]
}
如果页面中没有题目，返回空的 questions 数组。
只返回 JSON，不要有其他文字。
```

## API 调用

- 使用现有 API 配置（API Key、Base URL、Max Tokens）
- 请求格式同摘要功能
- 返回后解析 JSON 中的 questions 数组

## 文件变更

| 文件 | 变更内容 |
|------|----------|
| `popup.html` | 新增"答题"按钮 |
| `popup.js` | 新增 answerQuestions() 函数，发送 AI 请求 |
| `content.js` | 新增 createAnswerPanel() 和 renderAnswerPanel() |
| `messages.json` | 新增 i18n 文本 |

## i18n 文本

| Key | 中文 | 英文 |
|-----|------|------|
| answerQuestions | 答题 | Answer Questions |
| analyzingQuestions | 正在分析题目... | Analyzing questions... |
| answerResults | 答题结果 | Answer Results |
| noQuestionsFound | 未找到题目 | No questions found |
| question | 题目 | Question |
| answer | 答案 | Answer |

## 错误处理

| 场景 | 处理方式 |
|------|----------|
| API Key 未配置 | 显示错误，点击跳转设置 |
| 网络错误 | 显示错误信息和重试按钮 |
| 无题目 | 侧边面板显示"未找到题目" |
| AI 返回格式错误 | 显示"无法解析答案结果" |

## 约束

- 只在用户主动点击时触发
- 不自动检测，不修改页面 DOM 结构
- 侧边面板不干扰页面原有内容
