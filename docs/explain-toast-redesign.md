# AI 解释 Toast 优化设计

## 概述

优化划词"AI解释"功能的 toast 通知：位置改为右上角、增加60秒倒计时显示和关闭按钮。

## 行为对比

| 特性 | 当前 | 优化后 |
|------|------|------|
| 位置 | 底部居中 | 右上角 |
| 时长 | 4秒 | 60秒 |
| 倒计时 | 无 | 显示剩余秒数 |
| 关闭按钮 | 无 | 右上角 X 图标 |
| 计时起点 | toast 显示时 | 获取到解释结果后 |

## 交互逻辑

### 显示流程

1. 用户划词点击 "AI解释" 按钮
2. 显示 loading toast（如 "正在获取解释..."），位置右上角
3. API 请求完成
4. **倒计时从60秒开始**显示解释内容
5. 用户可点击关闭或等待自动关闭

### 计时规则

| 场景 | 行为 |
|------|------|
| API 请求中 | 不计时，显示 loading 状态 |
| 结果返回后 | 开始60秒倒计时 |
| 用户点击关闭 | 立即关闭，清除定时器 |
| 倒计时归零 | 自动关闭，淡出动画 |

### 定时器管理

- 使用 `setInterval` 每秒更新倒计时显示
- 每次显示新 toast 时 `clearInterval` 旧定时器
- 关闭时 `clearInterval` 防止内存泄漏
